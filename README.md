# TBD – Class Game Project

This repository contains the shared game project for the Gather Studio class.  
All teams contribute to this project through art, audio, writing, planning, and development.

## Class Site
https://sites.google.com/view/gatherstudio

Bookmark the class site. It contains lessons, schedules, role descriptions, and expectations.

## Project Summary
A player wakes up in a polluted wasteland where living trash creatures roam.  
They must survive, craft tools and weapons, explore dangerous and safe areas, and find a way home.

## World Overview
The surface world is a harsh wasteland filled with trash, smoke, and hostile trash beasts.  
Below the surface is an underground refuge lit by lantern mushrooms, where humans gather, trade, and rest.  
Somewhere in the world stands an enchanted tower, home to an ancient enchantress who may know the way home.

Tone: adventurous and mysterious, with moments of warmth and safety.

## Main Player Goal
Defeat trash beasts, craft items, survive the environment, and discover a way to return home.

## Team Contributions
Storytellers write the intro story, lore, and world details.  
Artists create characters, creatures, environments, and visual assets.  
Sound designers create music and sound effects.  
Developers build gameplay systems and interactions in Godot.  
Project managers track progress, priorities, and communication.

## Folder Structure
assets/ – art, audio, fonts  
scenes/ – game scenes (ui, world, actors, interactables)  
scripts/ – game logic  
data/ – story text and game data  
docs/ – planning documents and references
